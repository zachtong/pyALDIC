# Summary

Digital Image Correlation (DIC) is widely used in experimental mechanics for measuring full-field deformations and characterizing the mechanical behavior of materials [@sutton2009; @pan2018review; @idics_gpg_2018]. Among the available DIC post-processing formulations, local subset-based image tracking methods (e.g., the inverse-compositional Gauss–Newton (IC-GN) algorithm [@baker2004lucas; @pan2013fast]) are widely used because of their computational efficiency. However, their performance degrades under several challenging conditions that arise frequently in experimental practice, including low signal-to-noise images [@yang2019combining], large displacement gradients [@gupta2024estimation], and discontinuous kinematic fields such as associated with cracks [@poissant2010novel; @zhu2026pf], shear bands [@chen2017active; @ni2025revisiting; @ran2026comparative], and interfacial debonding or sliding [@rubino2019full]. To address these challenges, we introduced a hybrid local–global DIC image tracking formulation, called **Augmented Lagrangian DIC (AL-DIC)** [@yang2019augmented], in which independent local correlation problems are coupled to a global solver through the alternating direction method of multipliers (ADMM) [@boyd2011distributed]. The global step enforces kinematic compatibility, suppresses noise, and reduces isolated erroneous solutions that may arise from purely local correlation [@yang2019combining]. The performance of AL-DIC has been evaluated using the DIC Challenge 2.0 datasets and compared with that of other commonly used commercial and academic DIC codes [@dicchallenge2exme]. In addition, the AL-DIC formulation has subsequently been extended through adaptive spatial discretization to enhance its computational efficiency [@yang2021fast; @yang2018fast; @yang2022staq; @leu2026machine].

**pyALDIC** is an open-source Python package for 2D DIC that makes augmented Lagrangian digital image correlation (AL-DIC) available through both a desktop graphical user interface (GUI) and a programmatic interface (see \autoref{fig:overview}). Users can import image sequences, define regions of interest, select either conventional local subset-based DIC or AL-DIC, inspect full-field results, and export displacement and strain data. The computational core is accessible independently of the PySide6 GUI for scripted analysis. pyALDIC is distributed under the BSD-3-Clause license, with installation through PyPI (`pip install al-dic`), source code and documentation on GitHub <https://github.com/zachtong/pyALDIC>.

# Statement of need

Subset-based DIC estimates displacement by matching small regions of a reference image to a deformed image. It is efficient, but neighboring subsets are typically solved independently; noisy images and strong deformation gradients can therefore produce inconsistent measurements. A further difficulty occurs when a square subset spans a crack or hole boundary, so that the pixels within it may not share a single physically meaningful motion. These limitations matter when measuring localized deformation, fracture, shear bands, and other strongly heterogeneous mechanical responses.

AL-DIC addresses the trade-off between local correlation and global kinematic consistency by coupling local subset optimization to a global compatibility problem through an augmented Lagrangian formulation [@yang2019augmented]. Adaptive refinement and discontinuity-aware treatment extend this approach to complex specimen geometries [@yang2021fast; @yang2018fast; @yang2022staq; @leu2026machine]. However, the original research implementations were developed primarily in MATLAB. pyALDIC targets experimental mechanicians, materials researchers, and developers who need a freely available Python implementation that can be used interactively in the laboratory or incorporated into reproducible analysis pipelines without a proprietary-language dependency.

# State of the field

Several open-source DIC software packages have been developed to facilitate full-field deformation measurements. Ncorr provides a MATLAB-based graphical interface for subset-based DIC analysis [@blaber2015ncorr], while DICe offers a high-performance C++ framework for image correlation [@turner2015dice]. OpenCorr provides an extensible C++ library supporting two-dimensional DIC, stereo-DIC, and digital volume correlation (DVC) [@jiang2023opencorr]. Within the Python ecosystem, μDIC implements a global DIC formulation based on B-spline discretization [@olufsen2020mudic], whereas iCorrVision-2D provides a graphical workflow for subset-based correlation and displacement-field post-processing [@de2022icorrvision]. These packages offer complementary approaches to DIC analysis, differing in their numerical formulations, computational implementations, and user interfaces. \autoref{tab:dic_codes} summarizes selected features of representative open-source DIC software packages.

pyALDIC distinguishes itself by providing an open-source Python implementation of the augmented Lagrangian DIC (AL-DIC) formulation, which couples local subset-based image correlation with a global finite-element compatibility solver. Beyond implementing the original AL-DIC algorithm, pyALDIC integrates adaptive quadtree meshing, mask-aware subset splitting for displacement discontinuities, and both graphical and scriptable analysis workflows within a unified software package. These capabilities facilitate full-field deformation measurements involving complex specimen geometries, heterogeneous deformation, and cracks or other discontinuities. By making the AL-DIC framework accessible within the Python ecosystem, pyALDIC complements existing open-source DIC software and supports its broader adoption in experimental mechanics.

# Software design

pyALDIC separates its PySide6 graphical user interface (GUI) from the computational core, which comprises modules for image input, region-of-interest (ROI) definition, mesh generation, image correlation, strain calculation, visualization, and data export. This modular architecture enables the same analysis procedures to be accessed through either the desktop application or the Python API, supporting interactive use and reproducible batch processing. The GUI integrates image import, specimen masking, parameter selection, execution, and result visualization. Input supports TIFF, PNG, BMP, JPEG, JPEG 2000, and WebP image sequences; outputs include numerical data in NumPy, MATLAB, and CSV formats, as well as figures, animations, and HTML reports.

The correlation solver uses the inverse-compositional Gauss–Newton (IC-GN) algorithm for subpixel displacement estimation within individual subsets [@baker2004lucas; @pan2013fast]. Two solver modes are available. In *Local DIC* mode, subsets are correlated independently. In *AL-DIC* mode, the local estimates are coupled to a global finite-element displacement field through an augmented-Lagrangian formulation solved using the alternating direction method of multipliers (ADMM) [@yang2019augmented; @boyd2011distributed]. The global step promotes consistency between the local displacements, their gradients, and the finite-element representation. Providing both modes allows users to balance computational cost against the additional spatial coupling offered by AL-DIC.

To resolve localized deformation without uniformly increasing the number of correlation points, pyALDIC incorporates adaptive refinement of a four-node quadrilateral (Q4) mesh [@yang2021fast; @yang2022staq]. Refinement can be guided by mask or ROI boundaries and by user-defined regions; hanging-node constraints accommodate transitions between refinement levels. Near cracks, holes, or other masked boundaries, each correlation subset is restricted to the connected valid-pixel component containing its center. This mask-aware procedure avoids matching pixels from disconnected material regions and flags subsets with insufficient valid pixels, building on established discontinuity-aware DIC strategies [@poissant2010novel; @yang2022staq]. Initial displacements are estimated either by fast Fourier transform (FFT)-based cross-correlation [@jiang2015path] or by propagating estimates from user-defined seed points along mask-connected paths.

Computationally intensive operations are accelerated using Numba just-in-time compilation [@lam2015numba], which avoids a separate user-managed compilation step but introduces an initial compilation overhead. Chunked cross-correlation searches also reduce peak memory requirements for large image sequences. Together, these implementation choices provide flexible analysis workflows while retaining the distinct computational characteristics of the local and coupled local–global solvers.

# Research impact statement

The research value of pyALDIC builds on the established AL-DIC framework. To date, AL-DIC has been adopted for full-field deformation and strain measurements across multiple research areas, including studying metals and alloys deformation mechanisms and plasticity [@ni2025revisiting; @ran2026comparative; @ni2024automated; @ni2025temperature; @ozdur2021residual; @gu2026electric; @ni4836423automated; @ni2025mapping; @zhang5993534statistical; @he2026mapping; @hu2026oxygen; @makinen2022detection], laser welding of alloys [@pamarthi2023tailoring], cyclic behaviors of shape memory alloys [@chen2023cyclic], composites [@khouchani2024effect; @mammadli2025universal; @salian2021comparative; @roach2025multiscale], additive manufacturing and architected materials [@jirousek2023design; @jirousek2024discovering; @ye2024experimental; @fry2023tensile; @falta2018; @li2025characterization], soft materials and tissue mechanics [@summey2023open; @roy2025toughening; @sarkar2022quantification; @pearce2024evaluation; @tao2024experimental; @zhou2025vaginal; @yang2021smart; @mcghee2023high; @yang2026inertial; @yang2025imac; @bu2024high; @wei2026machine], civil/geophysics/wood and other construction materials [@harmal2023bioinspired; @grubii2023impact; @grubii2023measurement; @grubii2023influence; @falta2023mechanical; @grubii2023quality; @hafiz2025uniaxial], batteries and energy materials [@wu2023deformation; @courant2024design], fluid, electromagnetic and other physics [@zhang2023pattern; @zhang2025transitional; @leon2022influence; @zhang2025free]. It has also served as a benchmark for emerging DIC algorithms and has been included in community evaluations [@YangR3DICnet; @Ma21; @FENG2024108267; @kafka2024technique; @YANG2025115908; @gupta2024situ; @feng2026stereo; @Mangileva2024; @PUREZA2026102532; @schweickhardt2023digital; @venter2025sun; @wang2026interpretable; @yang2022serialtrack; @tong2026raftcorr] and reviews of open-source DIC software [@jin2023recent; @kopiika2024digital; @naufal2024digital; @kibrete2025free].

pyALDIC makes this methodology accessible through a publicly distributed, reproducible Python package with documented analysis workflows. pyALDIC itself has already been used by an independent research group to measure the anisotropic fracture of bedded shale under in-situ SEM three-point bending [@zhang2026anisotropic], and by the authors as a comparison baseline for a learning-based digital volume correlation method [@tong2026raftdvc]. It is also used in teaching: undergraduate laboratory courses at The University of Texas at Austin adopted it in 2026 (ASE 324L in spring and ASE 375 in fall). Its example datasets include experimental speckle-image sequences of uniaxial tension, with and without holes, and of large rotation, together with scripted batch-processing workflows; its automated tests add synthetic displacement fields, rigid-body motion, Mode-I cracking, and adaptive-mesh refinement. These cases exercise both conventional correlation and the adaptive, discontinuity-aware capabilities central to the software. The repository additionally provides more than 2,600 unit and integration tests and continuous-integration checks on Linux with Python 3.10–3.14, supporting software verification and maintainability.

Representative benchmarks for version 1.0.3 show that, after just-in-time compilation, a complete two-frame analysis of $512\times512$ and $1024\times1024$ pixel images processed approximately 13,500–14,000 points of interest per second with the Local DIC solver and 3,300–3,400 with the AL-DIC solver (three ADMM iterations). These measurements used $31\times31$-pixel subsets, an eight-pixel spacing, and a 24-thread Intel Core i7-13700F CPU. For a $4096\times4096$-pixel, three-frame benchmark, chunked initial-guess computation reduced peak memory usage from 36 GiB in version 0.4.1 to 12 GiB. These results are specific to the reported hardware and parameter settings; the benchmark scripts are included in the repository.

The parameter definitions, ROI conventions, refinement settings, and error-reporting outputs in pyALDIC are designed to be consistent with the iDICs *Good Practices Guide for Digital Image Correlation* [@idics_gpg_2018; @idics_gpg_2025]. This alignment reduces the learning curve for practitioners familiar with established DIC terminology and analysis workflows. Future development will continue targeting (i) extending pyALDIC to three-dimensional stereo-DIC based on the recently developed stereo AL-DIC formulation [@tong2025stereo3d], (ii) accelerating the IC-GN computational kernels using GPU computing, including Numba CUDA, and (iii) improving integration with computational mechanics workflows for experimental–computational field comparison, constitutive-model calibration, and data-driven model discovery [@wei2026machine; @jin2023recent; @flaschel2021unsupervised; @you2022physics; @pearce2022combining; @kirchhoff2024inference; @wihardja2025constitutive; @kumar2025comparative; @spencer2026full].

The source code, datasets, and documentation of pyALDIC are openly available at <https://github.com/zachtong/pyALDIC>. Contributions, feature requests, and issue reports are welcome through the project's GitHub Issues and Discussions pages.
