# pyALDIC examples

Two different things, for two different people.

## [`quickstart/`](quickstart/) — images to run the software on

Three short real-experiment speckle sequences, ready to open in the interface.
Start here if you want to *use* pyALDIC. Everything needed is in the folder;
there is nothing to download. [Its README](quickstart/README.md) gives the
subset size, step and solver settings to start from for each case.

## [`scripting/`](scripting/) — running pyALDIC without the interface

Worked examples of the Python API: batch-process many samples from one config
file, and replot exported results afterwards without repeating the
correlation. Start here if you want to *automate* pyALDIC.
[Its README](scripting/README.md) has the details.
